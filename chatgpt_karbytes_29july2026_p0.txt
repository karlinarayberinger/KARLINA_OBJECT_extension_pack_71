## What precisely is one credit?

A credit is a weighted token-accounting unit. It is not one request, one tool operation, one megabyte, one server-minute, or one joule of energy.

For a standard-speed GPT-5.6 Sol task, the current rate card is:

[preformatted_text]

| Token category | Cost per 1 million tokens | Equivalent per credit |
| -------------- | ------------------------: | --------------------: |
| New input      |               125 credits |          8,000 tokens |
| Cached input   |              12.5 credits |         80,000 tokens |
| Output         |               750 credits |    About 1,333 tokens |

[end preformatted_text]

Consequently, the approximate Sol calculation is:

_C = (125(_I) + 12.5(_K) + 750(_O)) / 1,000,000

where:

* (_I) = uncached input tokens

* (_K) = cached input tokens

* (_O) = output tokens

* (_C) = credits consumed

For example, a turn using 20,000 new input tokens, 80,000 cached tokens, and 4,000 output tokens would cost approximately:

2.5 + 1 + 3 = 6.5 credits 

OpenAI currently says GPT-5.6 messages average approximately **5–40 credits**, but individual turns can fall outside that range. See the current [Work/Codex pricing and credit rate card](https://learn.chatgpt.com/docs/pricing).

## Why a 900 MB audit may consume surprisingly little

If I run filesystem utilities across a 900 MB directory, the tools might inspect every file byte while returning only a compact inventory, duplicate list, hash table, or search result. The model may receive only that relatively small textual result—not 900 MB of tokenized content.

Likewise, examining a video may involve:

* reading metadata;

* obtaining a transcript;

* extracting selected frames;

* sampling particular time ranges; and

* returning condensed tool results to the model.

The original video’s byte size therefore does not translate directly into credits. Conversely, a much smaller collection of dense text could be expensive if its entire contents, extensive conversation history, and numerous tool results repeatedly enter the model’s context.

One final distinction: your Plus allowance is not necessarily a wallet of purchased credits that gets refilled every five hours. Plus provides a renewing included-usage allowance; separately purchased credits become available after that included allowance is exhausted. The [usage dashboard](https://chatgpt.com/codex/settings/usage) is the authoritative account-specific view of both.
